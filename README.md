## 🧩 Rubik's Cube Solver - Pro 3D Edition
**A Java FX / Python implementation of the Kociemba solver for Rubik's Cube.**

### 📖 Project Overview
Got stuck with Rubik's Cube? No problem! This **Java-based desktop application** gives you a near-optimal solution!  
This version combines **3D interactive cube** and **2D mini-map** with **background Kociemba solver**, giving the near-optimal solution.  
Designed with a clean **MVC-inspired architecture**, it uses **Java FX** for a vibrant UI and **Python** for background solver.

### ✨ Key Features
*   **3D interactive cube**: Click stickers to edit the cube to a state in which you are stuck.
*   **2D mini-map**: View each side of the cube on a simple, 2D mini-map.
*   **Kociemba notation**: Generates, processes, and displays standard Kociemba algorithms/notation for near-optimized solution paths.
*   **Background Python Solver**: Leverages efficient background processing to calculate solution states without interrupting or freezing the graphical UI.

### 🛠️ Tech Stack & Architecture
*   **Languages**: Java and Python
*   **GUI Framework**: Java FX
*   **Build System**: Maven
*   **Integration**: GraalVM

### 🚀 How to run it
*   Open the project in NetBeans (or your preferred IDE).
*   Clean and Build the project using Maven.
*   Run the `Launcher` class to start the solver.
